URDU NARRATION GOES HERE
========================

The spoken Urdu translation, one file per ayah, named exactly like this:

    001.mp3
    002.mp3
    003.mp3
    004.mp3
    005.mp3
    006.mp3
    007.mp3

.wav, .m4a, .ogg and .flac work too - keep the 001...007 names.

Each file should match the Urdu text shown on screen for that ayah. The
translation itself comes from data/al_fatihah.json.

Credit the narrator in config.yaml:

    translation_credit:
      urdu_narrator: "Their name"


CHECK YOUR FILES

    python run.py validate
